# Duo Store 🎮

Plataforma web moderna orientada al comercio electrónico de artículos de gaming, merchandising y accesorios digitales.

## 🚀 Características
* **Diseño Responsivo:** Adaptado para dispositivos móviles y de escritorio.
* **Modo Oscuro (Dark Mode):** Estética optimizada para gamers.
* **Optimización de Rendimiento:** Uso de *Intersection Observer* para carga fluida de elementos en pantalla.

## 🛠️️ Tecnologías utilizadas
* HTML5
* CSS3 / Flexbox / Grid
* JavaScript (ES6+)
